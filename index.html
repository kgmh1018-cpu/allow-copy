사용 방법

사이트가 막아둔 복사 기능을 북마크 클릭 한 번으로 되돌려요.

Safari는 보안 정책상 별도 설정이 필요해요. 최초 1회만 하면 돼요.

  1. Safari 메뉴 → 설정 → 고급 탭 → 개발자용 메뉴 보기 체크
  2. 상단 메뉴바에 생긴 개발자용 클릭
  3. 스마트 검색 필드에서 JavaScript 허용 체크

이후엔 다른 브라우저와 동일하게 사용할 수 있어요.

브라우저별 단축키로 북마크바를 켜세요.

  • Chrome · Edge · FirefoxCtrl+Shift+B
  • SafariCmd+Shift+B

드래그 설치를 지원하지 않아요. 새 북마크를 만들고 URL 칸에 아래 코드를 붙여넣으세요.

원하는 페이지에서 저장한 북마크를 누르면 바로 실행돼요.

드래그 설치를 지원하지 않아요. 아래 코드를 복사한 뒤 북마크에 등록하세요.

  1. 아무 페이지나 열고 북마크로 저장
  2. 저장된 북마크 길게 누르기 → 수정
  3. 북마크 이름: 복사 허용 (예시) / URL(주소): 복사한 코드로 교체 → 저장

주소창을 누르고 ㅂ 입력 (예시) → 등록한 북마크 이름(복사 허용) 누르기

⚠ 북마크 목록에서 직접 누르면 작동하지 않아요. 꼭 주소창에서 찾아 실행하세요.

복사한 내용을 붙여넣을 때 일반 텍스트로 붙여넣기(오른쪽 클릭) 또는 아래 단축키를 사용하세요.

  • Chrome · EdgeCtrl+Shift+V
  • SafariCmd+Opt+Shift+V

일부 앱에서는 단축키가 동작하지 않을 수 있어요.

복사 차단을 해제하는 과정에서 페이지 일부 기능이 영향을 받을 수 있어요. F5로 새로고침하면 원래대로 돌아와요.
